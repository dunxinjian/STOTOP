D2

节点抽屉状态机（打开 / 脏检查 / 切换 / 关闭）

抽屉全生命周期的状态与迁移条件，重点定义"带着未保存修改切换节点"的分支。

关闭→ 点节点 / Enter / 诊断定位→ 打开·净 240ms 滑入 · 焦点入首字段
打开·净→ 任意编辑→ 打开·脏→ 防抖 2s 自动保存成功→ 打开·净 脏态下顶栏胶囊=「✎ 编辑中…」
打开·脏→ 点另一节点→
不弹窗：先同步触发保存（本地状态必成功）→ 抽屉内容就地换血（不关不开，内容 crossfade 160ms）→ Tab 停留在同名 Tab
打开·脏（含校验错误）→ 关闭 / 切换→
允许离开：错误值保留在草稿并转为节点错误角标 + 诊断项；绝不锁死用户在抽屉里
打开·任意→ Esc / ✕ / 点画布空白→ 关闭· 焦点归还到来源节点卡片（无障碍要求，见 D8）

关键决策

  • 切换节点不弹"是否保存"：本地草稿模型下保存不会失败（写内存+防抖落库），弹窗是伪选择；企微/钉钉在这里都会弹窗打断，是我们明确不学的点。
  • 就地换血而非关-开：连续检查多个节点（诊断修复流）时抽屉不闪烁；Tab 位置保持（正在逐节点核对"字段权限"时切节点仍停在字段权限 Tab）。
  • 点画布空白=关闭：与"点节点=打开"对偶；拖拽选择等复杂画布手势不存在（结构化图），无手势冲突。

动效关键帧规格

三条曲线 + 全动效对照表。原则：位移用标准曲线、入场用减速、退场用加速且更快。

standard cubic-bezier(.2,.8,.2,1)
布局位移：节点让位/生长、画布平移、分支展开
decelerate cubic-bezier(0,0,.2,1)
入场：抽屉/弹层/菜单出现、toast 滑入
accelerate cubic-bezier(.4,0,1,1)
退场：关闭类，时长为入场 70%
动效属性时长曲线编排备注
"+" hovertransform scale120msstandard离开时 100ms 回落
插入菜单opacity + scale .92→1160msdeceleratetransform-origin 锚在"+"位置
节点让位/生长height / transform240 / 200msstandard串行，见 D1；用 FLIP 技术避免重排抖动
抽屉开 / 关transform translateX240 / 170msdecelerate / accelerate内容在 60ms 后 fade-in（防白闪）
分支横向展开width + opacity280msstandard各列 stagger 40ms，从左到右
落位高亮闪烁background400ms ×1ease-out主色 8% 底纹，不重复闪
干跑路径点亮stroke + 角标 fade每段 160msdecelerate沿路径顺序 stagger 80ms，"流动感"
诊断定位滚动scroll + outline 脉冲360ms + 2×600msstandard目标节点外环脉冲两次后停

动效原则

  • 150-300ms 区间为主，超过 400ms 的只有分支展开与干跑点亮（有信息传达职责的编排动效）。
  • 只动 transform/opacity（合成层），例外是节点生长的 height（配 FLIP 限定在局部容器）。
  • prefers-reduced-motion：位移类全部降级为 80ms fade；干跑路径点亮改为整体一次性高亮。
